# Emily para Windows

Este repositório distribui apenas os instaladores públicos da Emily para Windows.

Baixe o instalador mais recente em [Releases](https://github.com/vitor-sh/emily-windows/releases).

Na primeira abertura, escolha uma das opções:

- **Entrar com senha**: abre o perfil privado sincronizado protegido pela senha mestra.
- **Criar meu espaço sem senha**: cria um perfil independente, sem os chats, memórias ou preferências do perfil privado, e sem sincronização com os dispositivos dele.

Nenhuma senha mestra ou credencial privada em texto aberto é publicada neste repositório.
